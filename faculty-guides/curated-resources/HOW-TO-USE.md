# About this collection

**Original collection and primary attribution:** Lance Eaton, Ph.D., Anchor Insights Consultants.  
**Original source:** https://docs.google.com/spreadsheets/d/1lM6g4yveQMyWeUbEwBM6FZVxEWCLfvWDh1aWUErWWbQ/edit  
**Snapshot:** Uploaded workbook last updated November 7, 2026.  
**Individual entries:** 223.  

This directory provides a course-by-course index of policy examples contributed to Eaton's ongoing repository. Each individual page identifies the course, discipline, contributor, institution, reported reuse rights, and source spreadsheet row. The original Google Sheet is the authoritative source of the full policy wording.

## How to navigate

1. Open [README.md](README.md) to browse courses grouped by discipline.
2. Select a course to inspect its contributor, institution and reuse-rights metadata.
3. Use the original spreadsheet link and specified row to read the policy in full.
4. Check the original document for updates before adapting any policy.

## Attribution and reuse

- Lance Eaton is credited as the compiler; each policy remains credited to its named contributor.
- Contributor-specific reuse rights are transcribed verbatim from the uploaded spreadsheet. A missing or unclear entry should not be interpreted as permission to republish.
- These files provide original catalog metadata and navigation, **not copies of the contributed policy statements**.
- If you adapt or reproduce a specific policy, follow its stated reuse terms and cite the contributing educator.

## Keeping the catalog current

This is a snapshot. Changes in the live spreadsheet are not automatically synchronized with this GitHub directory.
